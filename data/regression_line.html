최소제곱법 기울기 실험실

점을 움직이고 숫자를 바꾸면서, 왜 (x편차×y편차)의 합을 (x편차²)의 합으로 나누는지 직접 확인해 보세요.

① 데이터와 회귀직선

파란 점을 마우스나 손가락으로 움직여 보세요. 표의 숫자를 직접 바꿔도 됩니다. 주황색 점은 평균점입니다.

학생 데이터 (드래그 가능)평균점최소제곱 회귀직선
x 평균12.50
y 평균30.00
기울기 a2.20
회귀식: y = 2.20x + 2.50

그래프의 세로 점선은 각 학생의 실제 점수와 회귀직선의 예측 점수 차이(잔차)를 나타냅니다.

② 숫자를 직접 바꿔 보기

초기 데이터는 첨부 자료와 동일합니다: A(5, 16), B(10, 23), C(15, 31), D(20, 50).

학생공부 시간 x시험 점수 y

변화 실험

평균점은 그대로 두고, 모든 점수의 평균으로부터의 거리만 늘리거나 줄입니다.
평균 공부 시간은 그대로 두고, x의 편차만 늘리거나 줄입니다.

슬라이더는 현재 데이터에서 평균을 기준으로 편차를 배율만큼 조정합니다. 표를 직접 수정하면 실험 배율은 1로 돌아갑니다.

③ 분자와 분모가 만들어지는 과정

현재 데이터에서 평균을 뺀 값과, 각 곱셈 결과를 확인하세요.

학생x 편차y 편차x편차 × y편차x편차²
합계——275.00125.00
분자 합계275
분모 합계125
기울기2.2
기울기 = 함께 움직인 양 ÷ x의 움직임 기준량
275 ÷ 125 = 2.2

④ 왜 나누면 기울기가 될까?

1. 직선의 기울기란?
가로(x)가 1만큼 변할 때 세로(y)가 얼마나 변하는지입니다. 그래서 단위도 '점수 ÷ 시간'처럼 됩니다.
2. 분모는 x의 편차² 합
x가 평균에서 얼마나 멀리 퍼져 있는지를 제곱으로 모은 기준량입니다. 음수와 양수가 상쇄되지 않게 합니다.
3. 분자는 x편차×y편차 합
각 학생의 x 움직임과 y 움직임이 같은 방향인지, 얼마나 함께 움직이는지를 x 기준으로 모읍니다.
4. 나누는 이유
분자는 'x의 움직임에 연결된 y의 움직임'을 담고, 분모는 그 x 움직임의 크기를 담습니다. 따라서 분모로 나누어 x가 1만큼 움직일 때의 y 변화량으로 환산합니다.
직접 확인해 보세요!
점수 편차 배율을 2배로 올리면 분자는 2배, 분모는 그대로, 기울기는 2배가 됩니다.
공부 시간 편차 배율을 2배로 올리면 분자는 2배, 분모는 4배가 되어 기울기는 절반이 됩니다.
조금 더 수학적으로 확인하기

회귀직선을 ŷ = a(x − x평균) + y평균 형태로 놓습니다. 각 점의 세로 오차는 y편차 − a·x편차입니다. 이 오차들을 제곱해 모두 더한 값이 가장 작아지도록 a를 정하면, 계산 결과 a = Σ(x편차·y편차) ÷ Σ(x편차²)가 됩니다.

즉, 분모의 제곱은 임의로 값을 부풀리는 장치가 아닙니다. 오차 제곱의 합을 가장 작게 만드는 조건을 계산하다 보면 자연스럽게 생기는 값입니다.

꼭 기억할 점
분모 125가 '실제 편차의 합'은 아닙니다. 편차를 제곱해 만든 기준량입니다. 분자도 같은 x편차를 포함해 계산하므로, 둘의 비율이 최적의 기울기를 결정합니다.

y절편과 회귀식 구하기

구한 기울기와 평균점을 이용해 y절편을 계산하고, 최종 회귀식을 완성해 보세요.

⑤ y절편과 회귀식 구하기

회귀직선은 반드시 평균점 (x평균, y평균)을 지납니다. 그래서 기울기 a를 구한 뒤 평균점을 대입하면 y절편 b를 구할 수 있습니다.

① y절편 b를 구해 보세요.

b = y − a × x = 30.00 − (2.20 × 12.50) = 2.50
y : y(시험 점수)의 평균 = 30.00 a : 기울기 = 2.20 x : x(공부 시간)의 평균 = 12.50

② 최종적인 회귀식을 써 보세요.

y = 2.20x + 2.50

위의 점을 움직이거나 표의 숫자, 슬라이더를 바꾸면 y절편과 회귀식도 현재 데이터에 맞게 다시 계산됩니다.
